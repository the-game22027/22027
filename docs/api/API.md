# API Contract — REST v1

Status: **Draft v0.1, design phase.** The OpenAPI document generated by `@nestjs/swagger` becomes the executable contract once endpoints exist; this file is the design source it must match. Real-time quiz battles (the only quiz mode, ADR-0010): see [`WEBSOCKET.md`](WEBSOCKET.md).

## 1. Conventions

| Topic | Rule |
|---|---|
| Base path | `/v1` (URI versioning via Nest `VersioningType.URI`). Breaking changes → `/v2` for affected routes only |
| Format | JSON, UTF-8, `camelCase` fields |
| Resource names | Plural nouns (`/matches`, `/leagues`); caller-scoped resources under `/me`; sub-resources owned by a parent (`/matches/{id}/prediction`) |
| IDs | UUID strings |
| Time | ISO-8601 UTC (`2026-11-07T19:00:00Z`). Time-sensitive responses include `serverTime` |
| Locale | `Accept-Language: ar` or `en`; default = profile locale. Affects question text and reference names (`name` is resolved from `names`) |
| Auth | `Authorization: Bearer <accessToken>` on everything except `@Public` routes (auth, health) |
| Correlation | Optional `X-Request-Id` (echoed back); every response includes `X-Request-Id` |
| Null vs absent | Absent = not applicable for this viewer; `null` = applicable but no value |
| Enums | UPPER_SNAKE strings; clients must tolerate unknown values (forward compatibility) |
| Validation | Unknown body fields are rejected (`400 VALIDATION_FAILED`) |

## 2. Pagination

Cursor (keyset) pagination everywhere lists can grow:

```
GET /v1/me/predictions?limit=20&cursor=eyJrIjoiLi4uIn0
→ 200 { "items": [ ... ], "nextCursor": "eyJ..." | null }
```

- `limit`: default 20, max 100.
- `cursor`: opaque base64url; clients must not parse it.
- Small fixed lists (competitions, my leagues) may return `{ "items": [...] }` without a cursor.

## 3. Idempotency

| Kind | Mechanism |
|---|---|
| Naturally idempotent writes | `PUT` replaces state: prediction, MOTM vote, profile fields |
| Create-or-return | `POST /battle-rooms/join` returns the room (`200`) when the caller is already a member; `POST /battle-rooms/{id}/start` returns the running battle when already started |
| Non-idempotent creates | `POST /leagues`, `POST /friend-requests`, `POST /leagues/join`, `POST /battle-rooms`: clients send `Idempotency-Key: <uuid>`; the server stores the response for 24h per (user, key); a different body with the same key → `422 IDEMPOTENCY_KEY_REUSED` |
| Optimistic concurrency (optional) | `ETag: "<revision>"` on predictions; `If-Match` on `PUT` → `412 PRECONDITION_FAILED` if another device changed it |

## 4. Errors (RFC 9457 problem+json)

```json
HTTP/1.1 409 Conflict
Content-Type: application/problem+json

{
  "type": "/errors/PREDICTION_LOCKED",
  "title": "Prediction is locked",
  "status": 409,
  "code": "PREDICTION_LOCKED",
  "detail": "Predictions for this match closed at kickoff.",
  "instance": "/v1/matches/0193.../prediction",
  "traceId": "a1b2c3",
  "errors": [ { "field": "picks[1].homeScore", "code": "min", "message": "must be >= 0" } ]
}
```

- `code` is the stable machine contract; clients localize messages from `code`. `detail` is English, for developers.
- `errors[]` only for `VALIDATION_FAILED`.
- Never reveal existence of resources the caller cannot see: a hidden prediction or a block → `404`, not `403`.

## 5. Core DTOs (shapes)

```ts
// ---- Auth ----
interface AuthTokens { accessToken: string; accessTokenExpiresAt: string; refreshToken: string; user: Me; isNewUser: boolean }
interface SessionInfo { id: string; platform?: string; deviceName?: string; createdAt: string; lastUsedAt: string; current: boolean }

// ---- Users ----
interface Me { id: string; displayName: string; username?: string | null; avatarUrl?: string | null; locale: 'ar' | 'en';
  favouriteTeamId?: string | null; identities: { id: string; provider: 'GOOGLE'|'FACEBOOK'|'X'; label: string }[];
  privacy: { predictionVisibility: string | null } }
interface PublicUser { id: string; displayName: string; username?: string | null; avatarUrl?: string | null }

// ---- Football ----
interface Team { id: string; name: string; shortName?: string; crestUrl?: string | null; type: 'CLUB' | 'NATIONAL' }
interface MatchSummary { id: string; competition: { id: string; name: string; code: string }; roundLabel?: string | null;
  homeTeam: Team; awayTeam: Team; kickoffAt: string;
  status: 'SCHEDULED'|'LIVE'|'FINISHED'|'POSTPONED'|'CANCELLED'|'ABANDONED';
  score?: { home: number; away: number; decidedBy?: string; penalties?: { home: number; away: number } } | null;
  predictable: boolean;                 // computed server-side
  myPredictionExists?: boolean }
interface MatchDetail extends MatchSummary { endedAt?: string | null; venue?: string | null; serverTime: string }
interface Competition { id: string; code: string; name: string; type: string; countryCode: string | null; isNationalTeams: boolean }
interface SquadPlayer { playerId: string; name: string; teamId: string; role: 'STARTER' | 'SUBSTITUTE'; shirtNumber: number | null }

// ---- Predictions ----
type Pick =
  | { type: 'RESULT'; outcome: 'HOME' | 'DRAW' | 'AWAY' }   // response only: derived from EXACT_SCORE (DEC-03)
  | { type: 'EXACT_SCORE'; home: number; away: number }
  | { type: 'MOTM'; playerId: string };            // disabled until DEC-08
interface SubmitPredictionRequest { picks: Pick[] }
interface Prediction { id: string; matchId: string; picks: Pick[]; revision: number; status: 'ACTIVE' | 'VOID';
  updatedAt: string; locked: boolean;
  score?: { points: number; breakdown: Record<string, unknown>; ruleSetVersion: number } | null }
interface FriendPrediction { user: PublicUser; picks: Pick[]; score?: { points: number } | null }

// ---- MOTM ----
interface MotmPoll { matchId: string; status: 'PENDING'|'OPEN'|'CLOSED'|'FINALIZED'|'CANCELLED';
  opensAt: string; closesAt: string; serverTime: string;
  candidates: { playerId: string; name: string; teamId: string; shirtNumber?: number | null }[];
  myVote?: { playerId: string; votedAt: string } | null;
  result?: { winnerPlayerIds: string[]; tallies?: { playerId: string; votes: number; share: number }[] } | null } // tallies exposure: DEC-06
interface CastVoteRequest { playerId: string }

// ---- Quiz battles (only quiz mode; real-time play happens on WebSocket) ----
type GameType = 'BUZZER' | 'CAREER' | 'WHO_IS_PLAYER' | 'GRID';         // ADR-0015; tolerate unknown values
interface MatchmakingTicket { ticketId: string; gameType: GameType; status: 'QUEUED' | 'MATCHED' | 'TIMED_OUT' | 'CANCELLED';
  queuedAt: string; botFallbackAt?: string | null; battleId?: string }
interface AnswerCatalog { version: string; entities: { id: string; kind: 'PLAYER'|'CLUB'|'NATIONAL_TEAM'|'COUNTRY'|'COMPETITION'|'COACH';
  names: { en: string; ar: string }; search: string[]; popularity: number }[] }   // search = normalized names + aliases (07 §5.7)
interface BattlePlayer { participantId: string; kind: 'HUMAN' | 'BOT'; user?: PublicUser;
  bot?: { displayName: string; avatarUrl?: string | null }; seat: number }      // bots always labeled (DEC-40)
interface BattleRoom { id: string; code: string; status: 'LOBBY' | 'IN_BATTLE' | 'CLOSED';
  host: PublicUser; members: { user: PublicUser; joinedAt: string }[];
  maxPlayers: number; gameType: GameType; expiresAt: string; currentBattleId?: string | null; createdAt: string;
  topics: string[]; difficultyLevel: 'MIXED' | 'EASY' | 'MEDIUM' | 'HARD' }   // ADR-0020; topics [] = General
interface BattleTopic { slug: string; name: string; counts: { MIXED: number; EASY: number; MEDIUM: number; HARD: number } }   // name in the caller's locale
interface BattleSummary { id: string; gameType: GameType; mode: 'MATCHMAKING' | 'ROOM'; hasBot: boolean; status: string;
  players: BattlePlayer[]; myScore: number; myPlacement?: number | null;
  outcome?: 'WIN'|'LOSS'|'DRAW' | null; endedAt?: string | null; endReason?: string | null }
interface BattleDetail extends BattleSummary {           // after completion only: no live answers leak
  rounds: { roundNo: number; questionId: string; reveal: unknown;          // same shape as WS round:result.reveal
    winnerParticipantIds: string[];
    actions: { participantId: string; kind: string; answer?: { entityId: string; name: string } | { number: number };
      cell?: number; correct?: boolean; points: number }[] }[] }
interface PlayState { queue?: MatchmakingTicket | null; room?: BattleRoom | null;
  battle?: { battleId: string; status: string } | null; serverTime: string }   // app resume

// ---- Leaderboards ----
interface LeaderboardRow { rank: number; user: PublicUser; points: number; isMe: boolean }
interface LeaderboardPage { period: { kind: 'WEEKLY'|'MONTHLY'|'SEASONAL'|'ALL_TIME'; key: string; startsAt: string;
  endsAt?: string | null; status: string }; category: string; items: LeaderboardRow[]; nextCursor: string | null }
interface MyRank { rank: number | null; points: number; around: LeaderboardRow[] }   // rank null: no points in this period yet
interface LeaderboardPeriod { kind: 'WEEKLY'|'MONTHLY'|'SEASONAL'|'ALL_TIME'; key: string; startsAt: string;
  endsAt: string | null; status: 'OPEN' | 'CLOSED' }   // LeaderboardPage.period has this shape

// ---- Leagues ----
interface League { id: string; name: string; description?: string | null; owner: PublicUser; memberCount: number;
  myRole: 'OWNER'|'ADMIN'|'MEMBER'; competitions: LeagueCompetition[]; createdAt: string }
interface LeagueCompetition { id: string; mode: 'PREDICTIONS' | 'BATTLES'; name: string; startsAt: string; endsAt?: string | null;
  filters: Record<string, unknown> }

// ---- Social ----
interface FriendRequest { id: string; from: PublicUser; to: PublicUser; status: string; createdAt: string }
```

## 8. Versioning and compatibility

- Additive changes (new fields, new enum values, new endpoints) are non-breaking; clients must ignore unknown fields and tolerate unknown enum values.
- Removing/renaming fields or changing semantics requires `/v2` for that route, with `/v1` kept alive until mobile app adoption allows removal (mobile clients update slowly).
- CI diffs the generated OpenAPI document against the committed one and fails on breaking changes without a version bump.
